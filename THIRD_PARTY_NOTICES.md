# Third-party components

Revisions are fixed in `deps.lock.json`. The vendored repositories retain their original copyright headers and license files. `patches/openvpn3-mbedtls-hostname-policy.patch` adds an explicit Mbed TLS hostname policy to OpenVPN 3 while retaining its certificate verification callback; `scripts/bootstrap-deps.ps1` applies this local source modification after checking the pinned revision.

OpenVPN source files carry `MPL-2.0 OR AGPL-3.0-only WITH openvpn3-openssl-exception` notices. This project selects MPL 2.0. The selected source, notices and license text must accompany distribution as required by that license. The pinned source remains available in `third_party/openvpn3` and from the source link above; preserve the corresponding source version when distributing a binary.

Mbed TLS source includes additional notices under its dual-license terms. No OpenSSL, LZ4, LZO, xxHash, JSONCPP, Android or ArkOvpn application code is linked by this project's CMake target. Mbed TLS framework is a build-time dependency.

The HarmonyOS skeleton is generated by DevEco CLI and retains Huawei's Apache 2.0 source headers where present. The build uses Huawei SDK/runtime libraries supplied with DevEco Studio, under their own terms.

Copies of the actual upstream license texts are packaged under `entry/src/main/resources/rawfile/licenses/`. Before redistributing a later release, recheck the actual linked components and preserve their notices; this document describes the pinned development build only.
